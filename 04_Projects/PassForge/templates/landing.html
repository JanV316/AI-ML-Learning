Personal Credential Vault

Vault credentials are encrypted symmetrically using Fernet (AES-128-CBC + HMAC-SHA256) with keys derived from your password. Plaintext secrets are never stored on disk.

📊

Password Health Assessment

Evaluates theoretical entropy, rule-based scoring, common dictionary matches, repeated characters, and password reuse across saved credentials.

🔑

Secure Password Generator

Uses Python's cryptographically secure secrets module to generate random passwords with enforced character set diversity.

🛡️

Salting & PBKDF2 Hashing

User authentication passwords use PBKDF2-HMAC-SHA256 with 600,000 iterations and 16-byte random salts. Verification occurs in constant time.
