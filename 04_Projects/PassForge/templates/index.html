🛡️ Security Concepts Overview

Secure Randomness

Uses operating system entropy sources via secrets.SystemRandom rather than pseudo-random numbers.

Rule-Based Analysis

Detects dictionary passwords, repeated characters, ascending/descending sequences, and repeating substrings.

Theoretical Entropy

Estimates bit strength using $E = L \times \log_2(R)$ based on active character pool size.

Salted PBKDF2 Hashing

Protects hashes against rainbow table attacks using 16-byte random salts and 600,000 PBKDF2 iterations.

Constant-Time Check

Compares password hashes in constant time to prevent timing side-channel attacks.
